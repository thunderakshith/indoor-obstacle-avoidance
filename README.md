# AI Powered Indoor Obstacle Avoidance

This project demonstrates a simplified AI-based indoor obstacle avoidance system
for autonomous robots or drones using computer vision.

## Tech Stack
- Python
- OpenCV
- NumPy
- (Conceptual ROS integration)

## Project Pipeline
1. Capture indoor camera/video input
2. Preprocess visual data
3. Detect obstacles
4. Make navigation decisions

## How to Run
```bash
pip install -r requirements.txt
python src/main.py
